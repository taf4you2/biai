# biai

Projekt analizy EEG dla zadania visual recall.

Najwazniejsze miejsca:
- `postepyprojektu.md` - dziennik zmian i postepow.
- `docs/STRUKTURA_PROJEKTU.md` - mapa folderow i plikow projektu.
- `scripts/` - skrypty do budowania datasetow, treningu i agregacji wynikow.
- `notebooks/` - notebooki eksploracyjne i dokumentacyjne.
- `manifests/` - manifesty sesji.

Podstawowe komendy sa opisane w `docs/STRUKTURA_PROJEKTU.md`.
